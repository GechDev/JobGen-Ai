# Contributing to JobGen

Thank you for your interest in contributing to JobGen! We welcome contributions from the community.

## How to Contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes and commit them: `git commit -m 'Add some feature'`
4. Push to the branch: `git push origin feature/your-feature`
5. Submit a pull request

## Code Style

- Follow Go conventions for backend code
- Use TypeScript for frontend code
- Run linters before committing

## Testing

- Write unit tests for new features
- Ensure all tests pass before submitting PR

## Issues

Report bugs or request features using the GitHub issues page.
